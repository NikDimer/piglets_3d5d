# AI Assistant — ИИ-ассистент для STE Slicer (3D/5D Additive Copilot)

Плагин для STE Slicer (глубокий форк Cura 3.6) по кейсу хакатона «Открой #Моспром»
от Stereotech / Росатом — Аддитивные технологии.

Чат-бот **в двух интерфейсах** — в окне прямо внутри слайсера (нативные QWidgets)
и в браузере (SPA на `http://127.0.0.1:8765`), с общей историей диалога. Лицо ассистента —
**маскот Кали** (лаймовый хамелеон): машет в покое, «думает» при работе агента
и радостно прыгает, когда ответ готов. Состояния маскота синхронизированы с агентом
в обоих интерфейсах. Агент через LLM и MCP-инструменты сам:
- загружает и **анализирует геометрию STL** (габариты, объём, нависания, осевая симметрия);
- выбирает **режим печати 3D (classic) / 5D Spiral (cylindrical) / 5D (cylindrical_full)**;
- подбирает **материал и профиль качества** под условия эксплуатации из ТЗ;
- **сориентирует модель** на столе / цилиндрической оправке;
- настраивает ~25 ключевых параметров печати (слои, стенки, заполнение, температуры,
  скорости, поддержки, адгезию);
- **запускает слайсинг** (реальный прогресс из сигналов бэкенда) и
- **экспортирует `project.3mf` + `result.gcode`** для сдачи;
- объясняет каждое решение инженерным отчётом.

## Состав

```
AIAssistant/
├── plugin.json              # манифест плагина (api 5)
├── __init__.py
├── AIAssistant.py           # Extension: HTTP-сервер (127.0.0.1:8765), мост в главный поток Qt,
│                            #   общий вход submit_chat для веб-чата и нативного окна
├── AIAssistantWidgets.py    # нативный UI на QWidgets: маскот-карточка в углу + панель чата
│                            #   (текст идёт через QPainter, минуя баг текстового рендера Qt Quick)
├── AIAssistantManager.py    # legacy: старый мост Qt/QML (не используется, оставлен для истории)
├── resources/qml/           # legacy: старые QML-окна (не используются)
├── resources/mascot/        # GIF маскота + статичные PNG-кадры (фолбэк без GIF-хендлера)
├── agent/
│   ├── mcp_server.py        # MCP JSON-RPC 2.0: initialize / tools/list / tools/call (13 инструментов)
│   ├── slicer_tools.py      # инструменты STE Slicer + геоанализатор STL (чистый Python)
│   └── llm_agent.py         # цикл агента (OpenAI Chat Completions + tool calling) + системный промпт
└── web/                     # SPA: index.html + style.css + app.js (без внешних CDN)
```

**Почему QWidgets, а не QML:** в Qt-сборке, поставляемой со слайсером, есть баг
глубокой рекурсии при рендере текста в Qt Quick scene graph — QML-окно чата могло
намертво вешать весь слайсер (см. `DESKTOP_VERSION_POSTMORTEM.md`). Виджеты рисуют
текст через `QWidget.paintEvent`/QPainter — это другой код-путь, баг обходится.
Окна чата — frameless `Qt.Tool`, они не встраиваются в scene graph слайсера.

Технически: Python 3.5-совместимый код, **только стандартная библиотека** + API слайсера
(`UM`, `steslicer`, `PyQt5`). Все обращения к сцене/настройкам/слайсингу выполняются
в главном потоке Qt через `app.callLater` + `threading.Event` (синхронный мост
`execute_on_main_thread`). Прогресс слайсинга берётся из сигналов
`backendStateChange`/`processingProgress` в потокобезопасный стейт.

## Установка

1. Установите и активируйте STE Slicer (лицензия по инструкции хакатона — окно ATSS,
   `.reg`-файл). Выберите принтер **Stereotech Hybrid 530 V5.2.4**.
2. Скопируйте папку `AIAssistant` в папку плагинов пользователя:
   `%APPDATA%\steslicer\7.10\plugins\AIAssistant`
   (в слайсере: **Справка → Показать папку конфигурации** → `plugins`).
3. Перезапустите STE Slicer.

## Использование

- **Расширения → AI Assistant → Чат Кали (в окне слайсера)** — маскот Кали появляется
  в правом нижнем углу; клик по нему открывает панель чата (markdown-ответы, карточки
  инструментов, пресеты, вложения файлов, настройки API, прогресс нарезки, кнопка 🌐
  открывает браузерную версию). Панель и маскот перетаскиваются, двойной клик по Кали —
  вернуть на место.
- **Расширения → AI Assistant → Открыть AI-чат в браузере** — полнофункциональная SPA
  (markdown-ответы, drag&drop, карточки инструментов, экспорт бандла).
- История диалога общая для обоих интерфейсов.

Быстрый просмотр нативного UI без слайсера (мок-агент проигрывает сценарий):

```
python tools/preview_widgets.py          # скриншоты в tools/preview_out/
python tools/preview_widgets.py --stay   # оставить окно открытым
```

## Настройка API

В окне чата (⚙️ в шапке) — Base URL, API Key, модель. Работает «из коробки»: в качестве
значений по умолчанию подставлены демо-данные организаторов, опубликованные на странице
кейса; пользователь может заменить их своими в настройках. Ключ хранится в настройках
приложения (`ai_assistant/api_url`, `ai_assistant/api_key`, `ai_assistant/model_name`).

| Поле | Значение по умолчанию |
|---|---|
| Base URL | `https://api.timeweb.ai/v1` |
| API key | демо-ключ организаторов из материалов кейса (меняется в UI) |
| Модель | `dashscope/qwen3.8-flash` |

## Как получить результаты для сдачи

Для каждой тестовой модели:

1. В чате напишите задачу (или вставьте текст ТЗ) и прикрепите STL
   (нативное окно — кнопка 📎; браузер — drag&drop).
2. Дождитесь, пока агент загрузит модель, выберет режим/материал/параметры,
   сориентирует деталь и завершит слайсинг (прогресс виден в шапке).
3. Нажмите **📦 Экспорт** (браузер) или быструю кнопку «Экспорт» (нативное окно),
   введите имя модели (например, `1. Шестерня`). Файлы появятся в
   `<папка конфигурации>\AIAssistant_results\<имя>\`: `project.3mf` + `result.gcode`.
4. Сделайте скриншоты переписки и положите их рядом как `chat_*.png`.
5. Итоговый архив: `plugin/` (этот код + README) и `results/<model_name>/…`.

## MCP-инструменты

Сервер MCP доступен по HTTP: `POST http://127.0.0.1:8765/mcp`
(JSON-RPC 2.0: `initialize`, `tools/list`, `tools/call`, `ping`).

| Инструмент | Назначение |
|---|---|
| `get_printer_and_settings_summary` | принтер, режим 3D/5D, материал, профиль, 25+ настроек |
| `search_settings_definitions` | поиск ключей настроек с описанием и options |
| `set_slicer_settings` | пакетная установка настроек |
| `set_printing_mode` | переключение classic / cylindrical / cylindrical_full |
| `list_profiles_and_materials` | доступные материалы и профили качества |
| `set_material_and_profile` | выбор материала/профиля, сохранение профиля |
| `load_and_analyze_model` | загрузка модели + геоанализ (нависания, симметрия, рекомендация 3D/5D) |
| `get_scene_objects` | список объектов на столе |
| `transform_model` | перемещение / поворот / масштаб + опускание на стол |
| `arrange_and_clear_scene` | авто-расстановка / очистка стола |
| `run_slicing` | запуск нарезки с ожиданием; при сбое возвращает причину: `backend_error` (текст окна ошибки `ui_message`, код `job_result`, исключение `job_error`) + `log_tail` — последние ошибки из журнала слайсера |
| `read_slicer_log` | журнал слайсера (steslicer.log): последние ошибки/предупреждения; агент обязан вызывать при любом сбое нарезки |
| `get_slicing_status_and_result` | статус, прогресс, время печати, расход материала |
| `export_project_and_gcode` | экспорт `project.3mf` + `result.gcode` |

## Отладка

Логи плагина пишутся через `UM.Logger` в `stderr.log` / `*.log` в папке конфигурации
(строки `[AI Assistant]`). HTTP-порт фиксирован: `127.0.0.1:8765`.
Если нативное окно не открылось (проблема загрузки QML), плагин автоматически
откроет браузерную версию — вся функциональность сохраняется.

## Возможные проблемы

- **5D-нарезка падает с ошибкой** — проверьте, что лицензия активирована (окно ATSS),
  и что выбран режим из трёх поддерживаемых: 3D / 5D Spiral / 5D
  (альфа-режимы `discrete`/`spherical` не используются).
- **«Настройки API» не сохраняются** — убедитесь, что плагин лежит именно в
  `%APPDATA%\steslicer\7.10\plugins\AIAssistant` и слайсер перезапущен.
- **Порт 8765 занят** — освободите порт или поправьте `ChatServer(("127.0.0.1", 8765), …)`
  в `AIAssistant.py`.
