# AIAssistant для STE Slicer

Плагин добавляет в STE Slicer AI-ассистента для подготовки 3D- и 5D-печати.
Основной интерфейс — безопасная QWidget-панель внутри слайсера. Также доступна
браузерная версия с той же историей диалога.

## Возможности

- анализ STL: габариты, объём, симметрия и нависания;
- выбор режима `3D`, `5D Spiral` или `5D`;
- подбор материала, профиля и параметров;
- ориентация модели на столе или оправке;
- запуск слайсинга с контролем зависания;
- экспорт `project.3mf` и `result.gcode`;
- 13 MCP-инструментов для управления слайсером.
- встроенное обучение пользователя на примере учебной шестерни;

## Установка

1. Установите STE Slicer и активируйте лицензию.
2. Выберите принтер **Stereotech Hybrid 530 V5.2.4**.
3. Скопируйте папку `AIAssistant` в:
   `%APPDATA%\steslicer\7.10\plugins\AIAssistant`.
4. Перезапустите STE Slicer.
5. Откройте меню **Расширения → AI Assistant**.

## Первый запуск

1. Откройте **Открыть AI-чат** или **Чат Кали (в окне слайсера)**.
2. Нажмите **Настройки**.
3. Укажите:
   - Base URL, например `https://api.timeweb.ai/v1`;
   - собственный API-ключ;
   - имя модели, например `dashscope/qwen3.8-flash`.
4. Приложите STL и напишите задачу: материал, нагрузка, среда эксплуатации
   и желаемая точность.

Ключ намеренно не входит в репозиторий. При повторном открытии настроек поле
ключа пустое; пустое поле сохраняет ранее сохранённое значение.

## Интерфейсы

### QWidget-панель

Нативная панель использует QWidget и QPainter, а не Qt Quick. Это важно для
данной сборки STE Slicer: старое QML-окно могло зависать при рендеринге
большого количества текста.

Маскот отображается без отдельной карточки и рамки. Нажмите на него, чтобы
открыть чат. Двойной клик возвращает маскот в исходный угол.

### Исходники маскота

Все изображения находятся в `plugin/AIAssistant/resources/mascot/`:

| Файлы | Назначение |
| --- | --- |
| `mascot_*_light.gif` | исходные большие GIF с фоном |
| `mascot_*.gif` | исходные GIF меньшего размера |
| `mascot_*_transparent.gif` | используемые анимированные GIF без фона |
| `mascot_*_transparent_frame.png` | статический fallback-кадр |

Полосы были частью `*_light`-изображений, а не рамкой Qt: фон был сохранён
в каждом кадре GIF. Для интерфейса используются `*_transparent`-версии —
из внешнего нейтрального слоя удалён фон, а глаза и цветные детали сохранены.

### Обучение

Кнопка **Обучение** в native-чате открывает короткий пошаговый тур по работе
Кали. В качестве реального примера используется встроенный в плагин файл
`resources/tutorial/Шестерня.stl`: пользователь видит путь от загрузки и
анализа геометрии до выбора режима, настройки параметров, слайсинга и экспорта.
Кнопка **Начать разбор шестерни** прикрепляет учебный STL к полю сообщения, но
не отправляет запрос без дополнительного действия пользователя.

Иллюстрации тура — отдельные прозрачные спрайты в
`resources/mascot/tutorial/`, подготовленные из листа `Стиль маскота.png`.
При первом запуске появляется вопрос о прохождении обучения. Ответ сохраняется
в настройках плагина, поэтому окно не навязывается повторно; открыть тур снова
можно кнопкой **Обучение**.

В режиме обучения основной маскот остаётся в своём обычном углу. Рядом с
левой панелью параметров появляется табличка с отдельным tutorial-спрайтом
Кали. На каждом шаге она показывает короткое объяснение одного параметра:
режима печати, высоты слоя, заполнения, стенок, материала и поддержек.
После завершения к сообщению автоматически прикрепляется учебная шестерня,
но запрос всё равно отправляет пользователь.
Табличка автоматически перемещается по вертикали вслед за соответствующей
группой параметров и располагается сразу справа от левой панели. Координаты
рассчитаны относительно главного окна слайсера, а не экрана или окна чата.
Пользователю не нужно двигать её вручную; одновременно открыта только одна
карточка обучения.

### Браузерная версия

Открывается по адресу `http://127.0.0.1:8765`. Она поддерживает markdown,
перетаскивание файлов, экспорт и просмотр карточек MCP-инструментов.

## MCP API

Доступные инструменты:

| Инструмент | Назначение |
| --- | --- |
| `get_printer_and_settings_summary` | Текущий принтер, режим и настройки |
| `search_settings_definitions` | Поиск ключей настроек |
| `set_slicer_settings` | Пакетная запись настроек |
| `set_printing_mode` | Переключение 3D/5D |
| `list_profiles_and_materials` | Список материалов и профилей |
| `set_material_and_profile` | Выбор материала и профиля |
| `load_and_analyze_model` | Загрузка и анализ модели |
| `get_scene_objects` | Объекты на столе |
| `transform_model` | Поворот, масштаб и позиция |
| `arrange_and_clear_scene` | Расстановка или очистка сцены |
| `run_slicing` | Запуск слайсинга |
| `get_slicing_status_and_result` | Статус и результат слайсинга |
| `export_project_and_gcode` | Экспорт 3MF и G-code |

HTTP endpoint: `POST http://127.0.0.1:8765/mcp`.
Для внешнего клиента передайте токен текущего запуска:

```text
X-STE-AI-Token: <token>
```

Браузерная SPA получает токен автоматически через cookie при открытии главной
страницы.

## Экспорт

После успешного слайсинга нажмите **Экспорт**. По умолчанию файлы сохраняются
в папку конфигурации:

```text
<config>\AIAssistant_results\<имя-модели>\
    project.3mf
    result.gcode
```

## Устранение проблем

### API-ключ не задан

Откройте **Настройки** и сохраните собственный ключ. Если ключ был задан ранее,
пустое поле не удаляет его.

### 5D-слайсинг завершается ошибкой

Проверьте лицензию ATSS, выбранный принтер и диаметр оправки
`cylindrical_mode_base_diameter`.

### Порт 8765 занят

Закройте другой процесс, использующий порт, и перезапустите STE Slicer.

### Плагин не загружается

Проверьте, что папка установлена именно как:

```text
%APPDATA%\steslicer\7.10\plugins\AIAssistant
```

Логи ищите в папке конфигурации STE Slicer.
