# AI Assistant для STE Slicer (piglets_3d5d)

ИИ-ассистент «Кали» для STE Slicer: чат с LLM-агентом, который сам настраивает
печать (режим 3D/5D, материал, профиль), работает со сценой, запускает слайсинг
и экспортирует 3MF + G-code. Плюс обучение при первом входе и справочник
параметров с подсказками.

## Установка

1. Установите STE Slicer 7.10 и активируйте лицензию (окно ATSS -> .reg).
2. Скопируйте папку `plugin/AIAssistant` в `%APPDATA%\steslicer\7.10\plugins\`
   (в слайсере: Справка -> Показать папку конфигурации).
3. Перезапустите слайсер. Маскот «Кали» появится в правом нижнем углу.

## Настройка API

Кнопка «Настройки» в шапке чата:

- Base URL: `https://api.timeweb.ai/v1`
- API Key: ключ организаторов (в исходниках не хранится, вводится здесь)
- Модель: `dashscope/qwen3.8-flash`

## Сборка / пересборка ассетов маскота (опционально)

Рабочих артефактов сборки нет — плагин на чистом Python + PyQt5 (входит в
слайсер). При желании пересобрать гифки маскота из исходных видео:

    python tools/mascot_floodfill.py none    # numpy, Pillow, ffmpeg

## Состав

- `plugin/AIAssistant/` — плагин (Python 3, PyQt5, без внешних зависимостей)
- `tools/` — скрипты генерации ассетов маскота
- `results/` — результаты по тестовым моделям (3MF, G-code, скриншоты чата)
