# piglets_3d5d

AI-ассистент для [STE Slicer](https://stereotech.ru/), который помогает
подготовить 3D- и 5D-печать. Пользователь описывает задачу и прикладывает
модель, а ассистент анализирует геометрию, предлагает режим печати, материал,
профиль и параметры, ориентирует модель, запускает слайсинг и экспортирует
результаты.

Плагин рассчитан на STE Slicer с принтером **Stereotech Hybrid 530 V5.2.4** и
поддерживает режимы `3D`, `5D Spiral` и `5D`.

## Возможности

- анализ STL-моделей: габариты, объём, симметрия и нависания;
- подбор режима 3D/5D, материала, профиля и параметров печати;
- ориентация модели на столе или оправке;
- запуск слайсинга с контролем зависания;
- экспорт `project.3mf` и `result.gcode`;
- нативный QWidget-чат внутри слайсера и браузерный интерфейс;
- встроенное обучение на примере учебной шестерни;
- 13 MCP-инструментов для управления сценой и настройками слайсера.

## Структура проекта

| Путь | Назначение |

Исходники STE Slicer в этот репозиторий не входят: для запуска требуется
установленная версия STE Slicer и её лицензия.

## Установка

1. Установите STE Slicer версии, совместимой с вашей сборкой плагина, и
   активируйте лицензию.
2. Выберите принтер **Stereotech Hybrid 530 V5.2.4**.
3. Скопируйте папку `plugin\AIAssistant` в каталог плагинов STE Slicer:

   ```text
   %APPDATA%\steslicer\7.10\plugins\AIAssistant
   ```

4. Перезапустите STE Slicer.
5. Откройте **Расширения → AI Assistant → Открыть AI-чат**.

Путь `%APPDATA%\steslicer\7.10` зависит от версии установленного STE Slicer.
Если используется другая версия, замените `7.10` на соответствующий каталог.

## Первый запуск

1. В чате откройте **Настройки**.
2. Укажите OpenAI-совместимые параметры:
   - **Base URL**, например `https://api.timeweb.ai/v1`;
   - собственный **API Key**;
   - имя модели, например `dashscope/qwen3.8-flash`.
3. Приложите STL, OBJ или 3MF и опишите задачу: материал, нагрузку, условия
   эксплуатации и требуемую точность.

API-ключ не хранится в исходниках и не включён в репозиторий. При повторном
открытии настроек поле ключа очищается визуально, но пустое значение не
удаляет ранее сохранённый ключ.

## Браузерный интерфейс и MCP API

При загрузке плагина запускается локальный интерфейс:

```text
http://127.0.0.1:8765
```

Браузерная версия поддерживает markdown, перетаскивание файлов, экспорт и
просмотр карточек MCP-инструментов. Для внешнего MCP-клиента используется
endpoint:

```text
POST http://127.0.0.1:8765/mcp
```

Передайте токен текущего запуска в заголовке:

```text
X-STE-AI-Token: <token>
```

Токен создаётся заново при каждом запуске плагина. Браузерный интерфейс
получает его автоматически через session-cookie при открытии главной страницы.

Доступны инструменты для:

- чтения и записи настроек, выбора режима, материала и профиля;
- загрузки и анализа модели, получения объектов сцены и их преобразования;
- расстановки и очистки сцены;
- запуска слайсинга, проверки результата и экспорта 3MF/G-code.

Полный список инструментов, формат запросов и troubleshooting находятся в
[`plugin/AIAssistant/README.md`](plugin/AIAssistant/README.md).

## Экспорт

После успешного слайсинга нажмите **Экспорт**. По умолчанию результаты
сохраняются в каталоге конфигурации STE Slicer:

```text
<config>\AIAssistant_results\<имя-модели>\
    project.3mf
    result.gcode
```

## Тесты и preview

Команды выполняются из корня репозитория. Тесты используют только стандартную
библиотеку Python и заглушки окружения слайсера, если не указано иное:

```powershell
python -X utf8 tests\test_plugin_smoke.py
python tests\test_run_slicing_stall.py
python tests\test_export_threading.py
```

Smoke-тест проверяет анализ всех семи моделей, бинарный и ASCII STL, MCP
JSON-RPC и системный prompt агента. Регрессионные тесты проверяют обработку
зависшего слайсинга и потокобезопасный экспорт.

`test_settings_keys.py` дополнительно проверяет ключи конкретной сборки
STE Slicer. Для него рядом с репозиторием должны быть доступны исходники
слайсера с файлами:

```text
STE-Slicer\STE-Slicer-master\resources\definitions\
```

Без этой директории тест можно пропустить.

Для быстрого просмотра QWidget-интерфейса без запуска слайсера:

```powershell
python tools\preview_widgets.py
```

## Устранение проблем

- **Плагин не загружается.** Проверьте имя и расположение каталога
  `AIAssistant`, версию каталога `%APPDATA%\steslicer` и перезапустите слайсер.
- **API-ключ не задан.** Сохраните ключ в окне **Настройки** и проверьте Base
  URL и имя модели.
- **5D-слайсинг завершается ошибкой.** Проверьте лицензию ATSS, выбранный
  принтер и параметр диаметра оправки
  `cylindrical_mode_base_diameter`.
- **Порт 8765 занят.** Закройте другой процесс, использующий этот порт, и
  перезапустите STE Slicer.

Логи ищите в каталоге конфигурации STE Slicer.
