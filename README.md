# piglets_3d5d — ИИ-ассистент для STE Slicer (кейс хакатона «Открой #Моспром» / Stereotech)

Плагин `AIAssistant` добавляет в STE Slicer чат-бота: пользователь описывает задачу
печати и прикладывает STL/фото, а LLM-агент через MCP-инструменты сам выбирает
режим **3D / 5D Spiral / 5D**, материал, профиль, ориентацию, запускает слайсинг
и экспортирует `project.3mf` + `result.gcode`.

## Структура репозитория

```
plugin/AIAssistant/   — исходный код плагина (ставится в %APPDATA%\steslicer\7.x\plugins\)
tests/                 — smoke-тесты (запускаются вне слайсера, UM заглушён)
_vendor/               — исходники STE Slicer и тестовые модели (техзадания + STL)
results/               — результаты по тестовым моделям (3MF + G-code + скриншоты)
```

## Быстрый старт

1. Установите STE Slicer, активируйте лицензию (окно ATSS → `.reg`), выберите
   принтер **Stereotech Hybrid 530 V5.2.4**.
2. Скопируйте `plugin/AIAssistant` в `%APPDATA%\steslicer\7.x\plugins\` и перезапустите слайсер.
3. Меню **Расширения → AI Assistant → Открыть AI-чат** → в шапке чата задайте
   **⚙️ Настройки API** (Base URL `https://api.timeweb.ai/v1`, ключ организаторов,
   модель `dashscope/qwen3.8-flash`).
4. Опишите задачу, приложите STL — агент настроит печать и отчитается.
   Кнопкой **📦 Экспорт** сохраните 3MF + G-code в папку результатов.

Подробности: `plugin/AIAssistant/README.md`.

## Тесты

```
.venv/Scripts/python.exe -X utf8 tests/test_plugin_smoke.py
```

Проверяются: геоанализатор STL на всех 7 тестовых моделях хакатона,
бинарный/ASCII STL-парсер, MCP JSON-RPC протокол (13 инструментов),
шпаргалки системного промпта.
